Changelog

Development history for Old Border Shandalar — sourced from the Forge repository

Mar 2026 Feb 2026 Jan 2026 Dec 2025 Nov 2025 Oct 2025 Sep 2025 Aug 2025
March 2026 New

New Content

  • Ante results popup — see which cards you won or lost after each ante match, with full card art and one-tap auto-sell

Bug Fixes

  • Fixed promo and special edition reward cards not appearing correctly
  • Fixed empty chest in Knight of Shadow dungeon
  • Fixed unwanted dialog popups in dragon lair maps
  • Unglued cards no longer appear in shops or random drops

Balance Changes

  • Adjusted life costs on several equipment items for better balance

Forge Engine

  • Fixed AI getting stuck in an infinite loop when it can't pay attack costs (e.g. Propaganda)
  • Booster pack rewards can now be restricted to specific editions
February 2026

New Content

  • Trophy System for Dungeon Master quest — 16 unique boss trophies that drop on defeat, transforming quest stages into collectible fetch objectives
  • Bonus starting cards system with updated color identity pack dialogue
  • Custom battle backgrounds and updated UI art for all battle and menu scenes
  • Updated adventure background texture for the overworld
  • New market and market portrait images

Bug Fixes

  • Fixed Colossus of Sardia not dying when killed (defeatDialog flag issue)
  • Fixed Sliver Queen access — now requires EITHER 3 lieutenant kills OR 8 foot-soldier kills
  • Fixed card variant resolution bypassing the allowedEditions whitelist
  • Removed Dungeon Master quest prologue to prevent repeated display on load
  • Fixed forest towns causing 2 variations to not be enterable
  • Fixed arena item rewards always giving the same item on every visit
  • Fixed various item icons and card rewards not displaying correctly

Balance Changes

  • Nerfed Vampire's Dagger: changed from Treacherous Vampire/-5 life to Vampire Hounds/-2 life

Forge Engine

  • Adventure save slots can now be sorted by most recently modified
  • Audio menu with volume sliders added to Forge context menu
  • Vertical scrollbar added to combat panel
  • Fix music volume resetting after window minimize/restore
  • Network multiplayer optimizations (reconnect, UI, chat, version mismatch warnings)
  • Fixed AI-controlled cards like Preacher and Arena not working properly against human players
January 2026 Massive Update

New Content

  • Dungeon Master Quest — a multi-tier quest tracking miniboss lairs: Tier I (creature lairs), Tier II (mage hideouts), Tier III (ancient masters), Bonus (Halls of Time, Ancient Diamond Mine)
  • Windwalker's Blessing speed item (+35% movement speed, late-game reward from legendary minibosses)
  • 69 new starter decks: 21 official WotC theme decks (Exodus, Urza's Destiny, Urza's Legacy, Stronghold, Visions, Weatherlight) + 48 themed decks from Stronghold through Scourge
  • Stronger starter decks added (4th Edition mono-color, 7th Edition dual-color)
  • Elder Dragon Lair Caves with unique items and dungeon effects (Nicol Bolas, Chromium, Vaevictis, Palladia-Mors, Arcades)
  • Artificer's Bazaar — 3 shops selling unique artifact equipment
  • Ancient Diamond Mine — trade shards/gold for Beta pack boosters
  • Dragon's Lair events for all five color biomes
  • Sphinx's Sanctum riddles lair — 6-question trivia challenge
  • Demon's Bargain dungeon added to black biome
  • Alternative quest path for Skep outer map (8-sliver kill alternative)
  • Life reward added to Sliver Queen drops
  • Adventure world-specific battle and menu background support
  • All preconstructed decks for old border era now work in "Chaos" starter mode

Bug Fixes

  • Fixed end palace gate bug blocking players with completed chapter 1 castles
  • Fixed Sliver Den barrier not unlocking after defeating crown slivers (wrong counter)
  • Fixed boss spawnRate to prevent 72 bosses from spawning on the overworld
  • Fixed end_palace teleports to correct False God boss rooms
  • Fixed color castles not appearing on world map
  • Fixed Elven Invasion quest spawning random enemies instead of elves
  • Fixed NG+ tutorial dialog not showing after using skip option
  • Fixed item reward names for Santa and Pharaoh enemies
  • Fixed deck card names, set codes, and block-appropriate lands across 35 starter decks
  • Fixed Shandalar shop card text false positives with word boundary regex
  • Fixed adventure ante erroring on missing sections
  • Dialog option added to skip castle quest completion

Balance Changes

  • Nerfed Urza due to player feedback
  • Reduced Ancient Silver Dragon's Dragon Blood drop rate to 30%
  • Balanced deckCard rewards added to minibosses
  • Item slot revamp (10 items renamed for consistency)
  • Standardized pile deck lands to 4th Edition
  • Added gamesPerMatch attribute to enemy configurations
  • Simplified end palace gate logic to only check enemiesDefeated >= 4

Forge Engine

  • Ante support added to Adventure mode (Play for Ante / Match Ante Rarity options)
  • Edition-specific starter decks for Standard mode
  • Chaos mode precons now filtered by allowed editions
  • Conjured cards removed from reward pool
  • Search bar added to Preferences menu
  • AI profile picker per AI player
  • AI proliferate now considers mana cost vs value
  • Fixed AI not sacrificing to avoid lethal life loss
  • Forge 2.0.09 released (January 16)
  • Forge 2.0.08 released (January 1)
December 2025

New Content

  • 60+ deck overhauls across boss, elite, miniboss, and standard enemy types
  • New decks: Minotaur elite (Anaba Warlord tribal), Crab tribal, Red wizard apprentice (4E themed)
  • Enhanced boss encounters with improved starting battlefield setups
  • Water of Youth equipment item (+2 life, starts with Fountain of Youth in play)
  • Updated castle maps with dungeon enchantments (Phyrexian Arena, Rhystic Study, Rowen, Fervor, Glorious Anthem)

Bug Fixes

  • Fixed End-Palace teleport bug
  • Fixed old border legality issues (added explicit edition codes to item cards)
  • Replaced Hivestone with Metallic Sliver|TMP for old border compliance
  • Removed cave maps with non-old-border creature types (Dinosaurs, Eldrazi, Kavu, Mimics)
  • Fixed tileset paths in 73 maps
  • Replaced modern cards with old border equivalents throughout vampire castle maps
  • Fixed illegal cards in temple maps (Griselbrand → Spirit of the Night, Damnation → Mutilate, etc.)
  • Replaced The Rack with Black Vise in Rustic Construct deck (anti-synergy fix)
  • Fixed mini-boss references and map references for bosses

Balance Changes

  • Rebalanced enemy life totals and rewards (apprentice 10→15, wizard 15→20)
  • Removed obsolete maps (temple_of_liliana, debug_map, templeofchandra)
  • Removed Temple of Gideon dungeon and 7 Jaya/Chandra themed enemies

Bug Fixes

  • Non-eligible cards removed from reward pool after matches
  • Fixed invalid item slot (#9149)
  • Fixed commander adventure mode crash in limited event

Bug Fixes & Improvements

Bug Fixes

  • Fixed crash when copying adventure decks with full slots

Bug Fixes

  • Disabled custom cards conformity check in Adventure mode
