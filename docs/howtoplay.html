★ How to Play ★
Get up and running in 4 easy steps!

1. Download Forge

Download the latest Forge snapshot from the official releases:

▶ github.com/Card-Forge/forge/releases

Forge requires Java 17 or newer. Get the latest JDK from oracle.com.


2. Launch Adventure Mode

Open Forge and select Adventure Mode.


3. Select Old Border Shandalar

Go to Settings and select "Shandalar Old Border" as your world.

⚠ IMPORTANT: Make sure "Show all card variants" is switched OFF. This ensures you only see old-border card art.



4. Start a New Game

Choose your color, pick a starter deck, and begin your adventure!
We recommend starting a fresh game rather than continuing a vanilla save.


💡 Tip: Fixing Card Images

If you see occasional new-border card art, clear your image cache:

Windows: C:\Users\<You>\AppData\Local\Forge\Cache\pics\cards
macOS:   ~/Library/Caches/Forge/pics/cards

Delete the contents of this folder and let Forge re-download the correct images.
